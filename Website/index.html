ScratchTrack 0.5

ScratchTrack is a desktop budgeting and cash flow tracking application.

ScratchTrack is inspired by the envelope budgeting philosophy but also supports workflows that don't involve rolling around with envelopes stuffed with cash.

SratchTrack was created in a fit of frustration after every alternative product moved to a cloud-based subscription model. If your budgeting software requires an entry in your monthly budget, it's a financial problem, not a solution.

ScratchTrack is free to use but tips are appreciated!

Scratch Track features

  • Easy one screen workflow
  • Support for traditional envelope budgeting workflows
  • Support for hybrid credit card envelope workflows
  • Continuous feedback as you work that alerts you to potential problems
  • Requires no special permissions and never sends any data over the internet
  • Small, fast, and portable
    • ScratchTrack is a single executable less than 400KB in size
    • ScratchTrack saves budget data to a single file (ScratchTrack.xml) in the same folder as the executable
    • ProTip: Copy ScratchTrack to your OneDrive / DropBox / GoogleDrive folder and work from any of your synced computers
