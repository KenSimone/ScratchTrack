Frequently Asked Questions

Q: What is ScratchTrack?

A: ScratchTrack is a desktop budgeting and cash flow tracking application based on the “envelope” budgeting philosophy. Information on envelope budgeting can be found here:

https://www.ramseysolutions.com/budgeting/envelope-system-explained
https://www.investopedia.com/envelope-budgeting-system-5208026


Q: Why is ScratchTrack?

A: I created ScratchTrack for myself after every single alternative option moved to a subscription model. ScratchTrack has reached a point where it's possibly useful to others, so here it is.

Q: What operating systems are supported?

A: ScratchTrack is designed for Windows 10 and 11. It probably works all the way back to Windows XP, but I haven't tried it.


Q: How do I install ScratchTrack?

A: ScratchTrack is a single file and there is no installer. Just copy it to your local machine and run it. If you’d like to add it to your start menu, right click it and select “Pin to Start”.

Pro tip: Keep ScratchTrack in a OneDrive / DropBox / Google Drive folder and your budget will follow you across your computers


Q: Who are you and why does ScratchTrack look like an application from the 1990s?

A: I'm a Win32 C++ developer. My day job is writing kernel code for a cyber security company. I haven't written user interface code since the 90s. Enjoy the throwback!


Q: I found a problem. Can I report a bug?

A: Yes! Please file bugs here


Q: I have a question. How can I ask it?

A: Visit the subreddit!


Q: Will ScratchTrack always be free?

A: ScatchTrack is currently supported by donations. If I invest more time and money into future versions I may charge a nominal fee. There will NEVER be a recurring fee and there will never be a version of ScratchTrack that costs more than the Spaghetti and Meatballs entree at the Olive Garden (dinner pricing, not lunch).
